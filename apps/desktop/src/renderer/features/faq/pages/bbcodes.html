BB-коды

  • [B], [I], [U], [S] - полужирный, курсив, подчёркивание и зачёркивание

    Делает выделенный текст полужирным, наклонным, подчёркнутым или зачёркнутым.

    Пример:
    Это [B]полужирный[/B] текст.
    Это текст [I]курсивом[/I].
    Это [U]подчёркнутый[/U] текст.
    Это [S]перечёркнутый[/S] текст.
    Вывод:
    Это полужирный текст.
    Это текст курсивом.
    Это подчёркнутый текст.
    Это перечёркнутый текст.

  • [COLOR=цвет], [SIZE=размер] - цвет текста, шрифт и размер

    Изменяет цвет, шрифт или размер выделенного текста.

    Пример:
    Это [COLOR=red]красный[/COLOR] и [COLOR=#0000cc]синий[/COLOR] текст.
    Это [SIZE=1]маленький[/SIZE] и [SIZE=7]большой[/SIZE] текст.
    Вывод:
    Это красный и синий текст.
    Это маленький и большой текст.

  • [URL], [EMAIL] - ссылки

    Создаёт ссылку из выделенного текста.

    Пример:
    [URL]http://www.example.com[/URL]
    [EMAIL]example@example.com[/EMAIL]
    Вывод:
    http://www.example.com
    example@example.com

  • [URL=ссылка], [EMAIL=адрес] - ссылки (дополнительно)

    Делает выделенный текст ссылкой на интернет-страницу или на адрес электронной почты.

    Пример:
    [URL=http://www.example.com]Ссылка на example.com[/URL]
    [EMAIL=example@example.com]Моя почта[/EMAIL]
    Вывод:
    Ссылка на example.com
    Моя почта

  • [USER=ID] - ссылка на профиль

    Ссылка на профиль пользователя. Как правило добавляется автоматически при упоминании пользователя.

    Пример:
    [USER=4315635]ahk_lzt[/USER]
    Вывод:
    ahk_lzt

  • [IMG] - изображения

    Показывает изображение, используя выделенный текст как URL-адрес.

    Пример:
    [IMG]https://lolz.team/styles/brivium/rezinc/xenforo/avatars/avatar_s.png[/IMG]
    Вывод:

  • [MEDIA=сайт] - вставка медиа-файлов

    Вставляет в сообщение медиа с разрешенных сайтов. Рекомендуется использовать кнопку добавления медиа в панели инструментов редактора. Одобренные сайты: Coub.com; Imgur; Music.yandex; Reddit; Rutube; SoundCloud; Spotify; Telegram; Twitch; Vimeo; YouTube;

    Пример:
    [MEDIA=youtube]oHg5SJYRHA0[/MEDIA]
    Вывод:
    Встроенный YouTube плеер появится здесь.

  • [LIST] - список

    Отображает нумерованный или маркированный список.

    Пример:
    [LIST]
    [*]Маркер 1
    [*]Маркер 2
    [/LIST]
    [LIST=1]
    [*]Запись 1
    [*]Запись 2
    [/LIST]
    Вывод:
    • Маркер 1
    • Маркер 2
    1. Запись 1
    2. Запись 2

  • [LEFT], [CENTER], [RIGHT] - выравнивание текста

    Изменяет выравнивание выделенного текста.

    Пример:
    [LEFT]По левому краю[/LEFT]
    [CENTER]По центру[/CENTER]
    [RIGHT]По правому краю[/RIGHT]
    Вывод:
    По левому краю​
    По центру​
    По правому краю​

  • [QUOTE] - цитата текста

    Отображает текст, как процитированный из другого источника. Можно также указать имя этого источника.

    Пример:
    [QUOTE]Процитированный текст[/QUOTE]
    [QUOTE=root]Что-то сказал[/QUOTE]
    Вывод:
    Процитированный текст
    Нажмите, чтобы раскрыть...
    root Что-то сказал
    Нажмите, чтобы раскрыть...

  • [SPOILER] - текст, содержащий спойлеры

    Скрывает текст, который может содержать спойлеры (преждевременно раскрытая важная сюжетная информация). Чтобы увидеть текст, нужно нажать кнопку спойлера.

    Пример:
    [SPOILER]Простой спойлер[/SPOILER]
    [SPOILER=Заголовок спойлера]Спойлер с заголовком[/SPOILER]
    Вывод:
    Простой спойлер
    Спойлер с заголовком

  • [CODE], [PHP], [HTML] - вставка программного кода

    Отображает текст на одном из языков программирования, выделяя синтаксис где это возможно.

    Пример:
    [CODE]Основной
    код[/CODE]
    [PHP]echo $hello . 'world';[/PHP]
    Вывод:
    Основной
    код
    Код 
    Основной
код
    echo $hello . 'world';
    PHP 
    echo $hello . 'world';

  • [PLAIN] - обычный текст

    Отключает распознавание BB-кодов внутри выделенного текста.

    Пример:
    [PLAIN]Это не [B]полужирный[/B] текст.[/PLAIN]
    Вывод:
    Это не [B]полужирный[/B] текст.

  • [API], [API=option] - Получить данные с сайта

    ББ-код получит данные с вашего сайта и вставит в сообщение. Также можно получить значение из JSON объекта, если указать путь к нему.

    Пример:
    [api]https://jsonplaceholder.typicode.com/todos/1[/api]

    [api=title]https://jsonplaceholder.typicode.com/todos/1[/api]
    Вывод:
    {
    "userId": 1,
    "id": 1,
    "title": "delectus aut autem",
    "completed": false
    }

    delectus aut autem

  • [BUTTON=option] - Кнопка

    Данный код работает аналогично коду url, но вместо обычной текстовой ссылки будет отображена ссылка в виде кнопки.

    Пример:
    [button=https://lolz.team/members/]Топ пользователей[/button]
    Вывод:
    Топ пользователей

  • [CENSOR] - Скрытый контент

    Открывается по клику

    Пример:
    [censor]Привет![/censor]

    Текст будет отображен после нажатия на него.
    Вывод:
    Привет!

    Текст будет отображен после нажатия на него.

  • [CLUB], [CLUB=option] - Скрытый текст для команды форума

    Информация внутри кода отображается только команде форума.

    Пример:
    [club]Привет, мир![/club]
    Отображается только участникам команды форума.
    Вывод:
    Скрытый контент для команды форума.
    Нажмите, чтобы раскрыть...

    Отображается только участникам команды форума.

  • [DAYS=option] - Скрыть текст по времени с момента регистрации

    Информация внутри кода отображается только определенным, зарегистрированным пользователям, которые провели на форуме указанное количество дней.

    Пример:
    [days=5]Привет, мир![/days]
    Отображается только зарегистрированным пользователям, которые зарегистрированы не раньше 5 дней назад.
    Вывод:
    Скрытый контент. Для просмотра информации необходимо провести 5 дней на форуме.
    Привет, мир!
    Нажмите, чтобы раскрыть...

    Отображается только зарегистрированным пользователям, которые зарегистрированы не раньше 5 дней назад.

  • [EXCEPTIDS=option] - Скрыть текст от пользователей

    Информация внутри кода отображается всем, исключая тех, кто указан в хайде.

    Пример:
    [exceptids=1,3,3124696]Привет, мир![/exceptids]
    Не отображается пользователям с идентификаторами 1, 3 и 3124696.
    Вывод:
    Контент запрещен для просмотра Alex, RaysMorgan, root.
    Привет, мир!
    Нажмите, чтобы раскрыть...

    Не отображается пользователям с идентификаторами 1, 3 и 3124696.

  • [LANG=option] - Текст в зависимости от языка

    Покажет текст, если у человека выбран определенный язык.

    Пример:
    [lang=ru]Будет показано только пользователем на русском языке[/lang]
    [lang=en]Will be shown only for users with English language[/lang]
    Вывод:
    Будет показано только пользователем на русском языке

  • [LIKES=option] - Скрыть текст по количеству симпатий

    Информация внутри кода отображается только определенным, зарегистрированным пользователям, набравшим необходимое количество благодарностей на форуме.

    Пример:
    [likes=5]Привет, мир![/likes]
    Отображается только зарегистрированным пользователям, количество симпатий на форуме которых больше или равно 5.
    Вывод:
    Скрытый контент. Для просмотра информации необходимо иметь 5 симпатий.
    Привет, мир!
    Нажмите, чтобы раскрыть...

    Отображается только зарегистрированным пользователям, количество симпатий на форуме которых больше или равно 5.

  • [LIKES2=option] - Скрыть текст по количеству лайков

    Информация внутри кода отображается только определенным, зарегистрированным пользователям, набравшим необходимое количество лайков на форуме.

    Пример:
    [likes2=5]Привет, мир![/likes2]
    Отображается только зарегистрированным пользователям, количество лайков на форуме которых больше или равно 5.
    Вывод:
    Скрытый контент. Для просмотра информации необходимо иметь 5 лайков.
    Привет, мир!
    Нажмите, чтобы раскрыть...

    Отображается только зарегистрированным пользователям, количество лайков на форуме которых больше или равно 5.

  • [PRICE], [PRICE=option] - Price

    Displays a price with a live-converted equivalent in the viewer's currency.

    Пример:
    [price]1000[/price]
    [price=USD]12.5[/price]
    Показывает цену с автоматическим пересчётом в валюту пользователя по текущему курсу. Без указания валюты сумма считается в рублях.
    Вывод:
    1000 ₽
    12.5 $ (≈ 981,07 ₽)
    Показывает цену с автоматическим пересчётом в валюту пользователя по текущему курсу. Без указания валюты сумма считается в рублях.

  • [SRCI], [SRCI=option] - Однострочный код

Обычно применяется в текстовых редакторах для облегчения чтения исходного текста программ. [SRCI] - автоматическая подсветка синтаксиса. [SRCI="подсветка"] - с определённым языком, где подсветка это: python (Python), ruby (Ruby), perl (Perl), php (PHP), xml (XML), html (HTML), css (CSS), javascript (javascript), java (Java), cpp (C++), sql (SQL), smalltalk (Smalltalk), ini (INI file), dos (DOS Style), bash (Bash Style), diff (DIFF). В скобках указаны оригинальные названия языков.

    Пример:
    [srci]config.php[/srci]
    Вывод:
    config.php

  • [TOOLTIP=option] - Tooltip

    Пример:
    [tooltip=5]Lolzteam[/tooltip]
    Вывод:
    Lolzteam

  • [USERIDS=option] - Скрытый текст для пользователей

    Отображение информации только для пользователей с указанными идентификаторами.

    Пример:
    [userids=1,3,3124696]Привет, мир![/userids]
    Отображается только для пользователей с идентификаторами 1, 3 и 3124696.
    Вывод:
    Скрытый контент для пользователей Alex, RaysMorgan, root.
    Нажмите, чтобы раскрыть...

    Отображается только для пользователей с идентификаторами 1, 3 и 3124696.

  • [VISITOR] - Имя пользователя

    Вместо BB-кода будет отображено имя пользователя, который просматривает страницу.

    Пример:
    [visitor][/visitor]
    Вывод:
    ahk_lzt
